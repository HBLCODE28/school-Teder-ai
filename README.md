# BeatSense AI Project

A Python music-genre classification web application.

## Repository setup

This repository was imported from a legacy Windows project. Build output, editor caches,
local databases, credentials, and generated artefacts are excluded through `.gitignore`.

## Development

Open the appropriate solution or project file. Commit source code, required assets, and
dependency manifests; do not commit generated output or secrets.

## Branches

`main` is the stable branch. For substantial work, create `feature/<description>` or
`fix/<description>`. Every branch must retain this README and update it when needed.
